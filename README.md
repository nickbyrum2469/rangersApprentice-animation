# Ranger's Apprentice: fan anime

A fan-made anime adaptation of John Flanagan's *Ranger's Apprentice*, Book 1 (*The Ruins of
Gorlan*). The story, voices, sound, music and animation are all generated by code, for free, on
one machine.

- **Series outline (the whole book, 10 episodes):** [`story/SERIES_OUTLINE.md`](story/SERIES_OUTLINE.md)
- **Episode 1 script:** [`story/ep01-the-choosing.md`](story/ep01-the-choosing.md)

## How an episode is made (audio first, like a real studio)

1. **Script:** `story/epNN-*.md`, in a strict format (scenes, dialogue, `[SFX]`, `[MUSIC]` cues).
2. **Music:** `npm run music` composes each cue with MusicGen (runs locally).
3. **Voices + mix:** `npm run audio` voices every line with Kokoro TTS (a separate voice per
   character), cleans the voices up (pitch/formant, EQ, de-essing, compression, room reverb),
   adds ambience, sound effects and ducked music, and masters to YouTube loudness.
   It writes `out/ep01/episode_audio.wav` and `timeline.json` (when every line is spoken).
4. **Animation:** `show/` is a Three.js anime renderer: cel-shaded characters with painted
   anime faces (3-frame lip flap driven by the voice track), hair built from locks, rim light,
   bloom, and sets for every scene. Scene files in `show/episodes/ep01/` choreograph the
   characters and cameras against `timeline.json`.
5. **Render:** `npm run render` draws the episode "on twos" (12 drawings/s at 24 fps, like TV
   anime) and muxes it with the soundtrack.

## Setup

```bash
npm install
pip install kokoro-onnx soundfile scipy torch transformers   # (CPU torch is enough)
# Kokoro voice model → tools/voices/ (kokoro-v1.0.onnx, voices-v1.0.bin from the kokoro-onnx releases)
# CC0 sound packs → audio/sfx_lib/ (Kenney "RPG Audio" and "Impact Sounds")
npm run preview            # then open http://localhost:8123/show/player.html
```
